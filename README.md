# 🚀 Dongwon Word Galaxy — 동원중 2학년 어휘 우주 탐험

동원중학교 2학년 영어 교과서 어휘를 영영풀이 게임으로 학습하는 우주 테마 웹게임.
첫 화면에서 **Lesson 1~8**을 골라서 진행할 수 있어요.

## 플레이
👉 https://aro-deeply.github.io/word-galaxy/

## 특징
- **각 과 5개 행성** — 단어 10개씩 분할 (46~50단어는 과별 자동 분배)
- **3가지 문제 유형 순환** — 영영풀이→영단어 / 영영풀이→뜻 / 뜻→영단어
- **목숨 ❤️ 7개**, 5연속 정답 시 자동 회복
- **15초 타이머** — 5초 이하면 카운트다운·BGM 가속·빨간 비네트
- **콤보 보너스** — 3/5/10연속 점수 배수 + 시간 보너스
- **별점 · 배지 10종 · 오답 복습** — 동기부여 시스템 다층
- **lesson별 진행 저장** — localStorage로 별·배지·점수 누적
